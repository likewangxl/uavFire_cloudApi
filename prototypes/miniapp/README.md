# 无人机火情智巡 · 小程序交互预览

浏览器预览：[http://localhost:8090/](http://localhost:8090/)。这是用于评审页面与交互的独立前端原型，使用虚构示例数据；不是微信开发者工具可导入的原生小程序。

## 本地运行

在本目录执行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 8090 --strictPort
```

开发服务只监听本机。PC 系统仍使用 8080；该原型无需启动后端或配置微信 AppID。

```sh
npm run check:runtime
npm run build
```

## 可体验内容

| 页面 | 交互 |
| --- | --- |
| 首页 | 今日指标、优先关注事件、任务进度、快捷入口、林区范围切换 |
| 任务 | 关键词搜索、状态筛选、任务概览、航点顺序、进度时间线、关联事件与报告 |
| 态势 | 风险与处置状态筛选、事件详情、影像待接入提示、位置精度说明 |
| 报告 | 状态筛选、生成过程、结构化报告、收藏与取消收藏、关联任务 |
| 我的 | 登录与组织绑定流程演示、表单校验、待审核/已绑定/已停用状态、通知偏好 |

顶部“示例场景”可切换暂无数据、数据延迟、连接异常；异常状态支持模拟重新加载。浏览器右上角可切换 iPhone 与 Pixel 10 设备框。

收藏和通知偏好保留于当前页面会话，刷新后重置。绑定状态用于演示流程，离开页面后重置；请仅输入虚构信息。时间、林区、航空器数量、任务与报告均为固定示例，不代表当前系统运行情况。

## 与原生工程的关系

- 原生微信工程继续位于 `../../miniprogram/`，后端契约见 `../../docs/miniprogram/`。
- 此版本不请求业务后端，不实施微信登录、通知授权、真实审核、签阅、归档、地图定位、媒体播放或飞行操作。
- 航线展示为航点顺序预览，报告为结构化示例；真实地图、媒体、报告文件及实时数据留待后续接入。
- 页面和流程确认后，将布局、交互状态与数据展示规则迁移到原生微信工程，再开展接口联调及微信真机验收。

## 文件与验证

业务页面在 `src/Prototype.tsx`，页面样式在 `src/prototype.css`。`src/mobile/` 为设备、滚动、键盘和页面转场运行时；完整性校验通过后再构建。

验证记录见 [design-qa.md](design-qa.md)，截图位于 `qa/`。本次通过浏览器交互验证和生产构建；浏览器设备框检查不等于微信真机验收。
