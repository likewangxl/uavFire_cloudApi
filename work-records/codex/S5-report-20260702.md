## 实现摘要

- `PreflightRule` 定义 `id / description / check(context)`，返回 `PASS / BLOCK / WARN`。
- `PreflightRuleEngine` 注册 R01-R15，支持 `fc100.preflight.rules.*` 开关。
- `PreflightContextFactory` 装配 incident、fire_event、FC100 mission draft、DELIVERY_PRIMARY 分配、Delivery Sync 设备属性、S4 lease、S4 command queue、合规留证、资质档案、DeliveryHub health、UOM 边界检查结果。
- `RealPreflightGate` 在 dispatch 前运行预检并落库；BLOCK 时抛出 `PreflightBlockedException`，全局异常响应 `data` 返回结构化 `PreflightResult`。
- `OperationIncidentServiceImpl.dispatch` 预检通过后只推进 `CONFIRMED -> DISPATCHING`，满足一期派发门禁语义。
- R09 默认 `NoReferenceUomBoundaryChecker` 仅 WARN，不自动调用 UOM/USS。
- 合规 controller 注释明确：接口只记录人工报备/批复结果，不自动对接外部空域系统。
