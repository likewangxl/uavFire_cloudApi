## Command Channel Investigation

`DualStreamServiceImpl.issueCommand` enqueues commands in the backend in-memory dual-stream queue (`commandByDrone` / `commandQueueByDrone`). The RC Plus agent takes them through:

- backend endpoint: `GET /manage/api/v1/dual-stream/agents/{drone_sn}/command`
- agent client: `AgentBackendClient.pollCommand`
- agent coordinator: `CommandPollingCoordinator.pollLegacyDualStreamCommand`
- execution target: `DualStreamSessionManager.executeCommand`
- ack endpoint: `POST /manage/api/v1/dual-stream/agents/{drone_sn}/command/ack`

Before this task, `DualStreamCommandDTO` had no `urgent` or priority field. The backend MSDK command DTO also has no urgent/priority field.

Agent urgent polling exists, but its current wiring is not a filter over dual-stream commands. In `AppServices`, `AgentRuntimeLoop` receives:

- normal poller: `CompositeCommandPoller(listOf(thermalHotspotMonitor, dualStreamPoller, waylineRouter))`
- urgent poller: `msdkControlPoller`

`AgentRuntimeLoop.DEFAULT_URGENT_COMMAND_INTERVAL_MS` is `500`, but that loop calls `msdkControlPoller`, whose `CommandPollingCoordinator` is configured with `pollLegacyDualStream = false`. It therefore polls only:

- `POST /manage/api/v1/msdk/devices/{aircraftSn}/commands/poll`

The normal 5s runtime loop is still the path that polls `/dual-stream/agents/{droneSn}/command`.

## Urgent Landing Status

Backend-side urgent marking was landed as the minimum compatible change requested for an unsupported command model. It is serialized on dual-stream command responses for the target four commands.

This alone does not make the current agent fetch those dual-stream commands at 500ms, because the agent urgent loop does not poll the dual-stream queue.

Required follow-up for agent-side acceleration:

- Option A: make the urgent poller also call legacy dual-stream polling and skip or prioritize commands using `AgentCommandResponse.urgent`.
- Option B: move/bridge these thermal focus and measurement commands into the MSDK command queue that the existing 500ms urgent loop already polls.
- In either option, agent models need an `urgent` field if the dual-stream DTO path is used.
