# 驾驶舱页面原型

独立 Vue 交互原型，用于确认页面结构与操作流程。沿用项目深色主题、Ant Design 图标与 MapLibre，不修改正式驾驶舱路由。

## 预览

在 `frontend` 目录运行：

```sh
./node_modules/.bin/vite --config prototypes/cockpit/vite.config.mjs
```

打开 http://127.0.0.1:5188/ 。直接访问 `#overview`、`#video`、`#events`、`#tasks/routes`、`#operations/flight`、`#devices`、`#management/media` 可切换页面。

```sh
./node_modules/.bin/vite build --config prototypes/cockpit/vite.config.mjs
```

## 页面职责

| 页面 | 保留内容 | 主要操作 |
| --- | --- | --- |
| 运行总览 | 待复核事件、执行中任务、需关注设备三个计数；态势图；待办；任务摘要 | 点击事件、飞机或任务进入详情 |
| 视频监控 | 右侧飞机缩略图、左侧自由播放区、高清名额 | 拖入/点击添加、移动缩放、单窗放大、关闭、一键平铺 |
| 火情事件 | 左侧紧凑列表、中间现场图片、右侧处置时间轴与详情 | 筛选事件、切换/放大图片、折叠记录、查关联任务、模拟复核 |
| 任务中心 | 航线库、地图规划、巡检任务、执行监控、历史记录 | 新建/编辑航线、示例导入、创建任务、模拟下发/暂停/完成、再次执行 |
| 专业作业 | 飞行控制、灭火与投送、任务审批 | 镜头与控制状态演示、准备/审批/执行反馈 |
| 平台管理（右上角齿轮） | 媒体资料、维护、固件、成员、地图与空域 | 资料预览与关联事件、维护检查演示、角色编辑、地图查看 |
| 设备管理 | 状态、电量、上传档位、视频链路 | 搜索筛选、查看详情与画面 |

## 本次新增流程（2026-09-06）

1. 打开任务中心 → 航线库 → 编辑航线，在地图添加航点，调整航高、速度和航点动作，保存。
2. 创建巡检任务，选择兼容机型的飞机与执行方式，再模拟下发。
3. 执行监控中暂停、继续或模拟完成；在历史记录点击再次执行，生成新的待执行任务，原记录保留。
4. 专业作业 → 灭火与投送，填写说明并提交演示审批，通过后回到任务详情模拟执行及反馈。
5. 右上角齿轮进入平台管理，查看媒体、设备维护、固件、成员权限与地图入口。

详细对应关系见 [feature-coverage.md](feature-coverage.md)。

## 原有功能体验顺序

1. 首页点击一条待复核事件，查看证据和关联任务。
2. 点击“查看现场画面”，进入对应飞机的单路聚焦；通过“关联火情”返回。
3. 点击“人工复核”，填写说明并保存，首页待办数量同步变化。
4. 视频页搜索第 5 架飞机，把缩略图拖入主播放区；拖动窗口标题移动，拖右下角调整大小。也可点击缩略图添加。
5. 点击“申请高清关注”，选择让出名额的飞机；放大或增加窗口不会自动增加高清名额。
6. 点击“一键平铺”整理当前画面；窗口右上角可放大、还原或关闭；“恢复四画面”回到四个默认窗口。
7. 设备页筛选“需关注”，检查低电量与视频弱网详情。
8. 底部“重置演示”恢复初始数据。视频窗口布局自动保存在本机，刷新或切换页面后保留；其他示例业务状态刷新后重置。

## 数据和实现边界

- 20 架飞机、事件、任务、经纬度、时间、电量、状态均为示例。界面固定显示“交互原型 · 示例数据”。
- 视频区域使用项目既有历史图片，逐画面标明“历史样张 · 非实时”；没有建立媒体播放连接。
- 高清 4 Mbps、低清 0.5 Mbps，对应 `4×4 + 16×0.5 = 24 Mbps` 的目标视频净码率；原型不测量真实流量和延迟。
- 复核、航线、巡检任务、投送审批、高清切换均为内存演示，不调用业务接口、Agent、飞控或真实视频授权接口。航线草稿、巡检任务和投送审批跨主页面保留，刷新或重置后恢复。
- KMZ 导入只提供内置示例，不解析真实文件；地图与空域管理为入口/概览，未实现限制区绘制；固件页只模拟检查，不升级；成员角色仅演示。飞行工作台使用模拟遥测与历史图片。
- 底图采用标准 OpenStreetMap 瓦片，保留署名；生产环境应继续使用项目正式批准的地图源。底图和可选 Google 字体依赖外网，字体有本地中文回退。
- 地图以部分示例飞机点位说明交互，航迹为示例；不能用于作业规划。
- 本页验证信息架构，不替代真实 20 架飞机的视频、网络与飞行验收。

## 文件与素材

`TaskCenter.vue` 与 `PlanningMap.vue` 为任务和地图规划工作区，`planning-data.js` 存放可复用航线；`OperationsCenter.vue` / `operations-state.js` 为专业作业与跨页审批状态；`ManagementCenter.vue` 为平台管理；`workbench.css` 为新增工作区样式。

`App.vue` 为页面和演示交互，`EventWorkspace.vue` 为火情三栏工作区，`VideoWorkspace.vue` 为缩略图与自由窗口，`video-layout.js` 为布局边界与存储，`data.js` 为数据，`PatrolMap.vue` 为示例地图，`style.css` 为共享样式。

`assets/visible.jpg`、`assets/thermal.jpg` 来自项目 `docs/promo/assets/leader_20260711`；`field.jpg`、`fire.jpg` 来自 `docs/promo/assets/shots` 的既有现场图片，未编辑图片内容。

## 自由视频工作区：正式接流要求

这次完成的是可操作的前端布局原型，图片仍为历史样张。真实媒体接入继续遵循原有 4 高清 + 16 低清方案：

- 按设备、镜头建立共享接收会话。同一设备在缩略图和大窗出现时复用媒体来源，避免两个播放器各自再建立网络拉流连接。
- 大窗数量与高清名额是两个独立状态。新增或放大低清窗口仍为低清；需要高清时走后台名额授权，确认生效后再改标签。
- 缩略图列表只渲染可视范围的活动画面；滚出范围、隐藏页面、关闭窗口后按订阅引用释放相应资源，保留其他观察者仍需要的会话。不能将“暂停 HTML 视频渲染”误认为已节约飞机上行带宽。
- 重用接收流不等于浏览器一定只解码一次。真实接入时应测量解码器数量、GPU、帧率和页面内存；可对已在大窗播放的飞机复用其帧生成缩略图，避免重复解码。
- 布局按播放区归一化坐标存储，窗口移动和缩放不应销毁重建播放器。组件卸载、指针取消和页面离开都需要正确清理监听和媒体引用。
- 窄屏下缩略图改为底部横向列表；触屏使用点击添加，标题与缩放手柄支持 Pointer Events。此原型保留方向键移动/调整大小作为替代操作。

浏览器 API 依据：[Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events)、[HTMLMediaElement.srcObject](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/srcObject)。这些 API 支持交互及媒体绑定，不代表已经完成真实多机网络验收。

## 火情事件三栏布局（2026-09-06）

- 桌面左侧为 220–280px 事件列表，中间自适应显示完整现场图片，右侧为 310–390px 处置详情。左右栏分别滚动；现场画面及底部操作保持可见。
- 右侧依次显示当前进展、单位/负责人、可折叠处置时间轴、事件详细信息。时间轴包含时间、人员或提醒对象、内容及结果；仅显示当前事件已有记录。
- 点击缩略图切换图片，放大图片打开可用 Esc 关闭的大图弹窗。只有红外样张的事件不会重复列出相同图片；其他事件的红外图片明确标为参考样张。
- 人工复核更新状态、负责人、结构化时间轴及首页待办。演示日期固定为 2026-09-05，复核时间顺延到该事件最后记录之后；刷新恢复初始业务数据。
- 小于等于 1000px 时事件列表横向排列，图片和处置栏并排；小于等于 700px 时转为图片在上、时间轴在下的单列布局。
- 处置人员、单位、消息提醒和记录均为原型样例。提醒记录只用于展示，没有发送通知或调用业务服务。
