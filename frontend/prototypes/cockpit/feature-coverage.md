# 现有项目功能与本版原型对应

2026-09-06。本表用于评审导航与业务流程；不表示正式系统已迁移或具备设备执行能力。

| 原有能力 / 源码线索 | 新入口 | 本版完成程度 |
| --- | --- | --- |
| 驾驶舱、态势与待办 | 运行总览 | 保留，增加规划、航线库、投送、媒体快捷入口 |
| livestream 与多机视频 | 视频监控 | 保留自由窗口、拖动缩放、4 高清名额演示 |
| fire-events / operation-incidents | 火情事件 | 保留三栏与模拟复核、关联任务 |
| projects/wayline.vue 的航线库、创建、编辑 | 任务中心 → 航线库 / 航线规划 | 可点地图增点、改坐标/高度/动作、保存新旧航线 |
| wayline.vue 的 KMZ 导入 | 任务中心 → 导入航线 | 仅内置 KMZ 示例体验，未接真实解析 |
| task/CreatePlan.vue 的计划创建 | 任务中心 → 巡检任务 | 选择航线、兼容机型飞机、立即/定时方式，创建待执行记录 |
| 航线执行、进度与再次执行 | 任务中心 → 执行监控 / 历史记录 | 模拟下发、暂停、恢复、完成；每次执行独立编号，已完成记录保留 |
| 专业驾驶舱与飞行控制 | 专业作业 → 飞行控制 | 地图、历史画面、参数和控制状态演示，无真实指令 |
| fire-missions 与投放任务、载荷、审批 | 专业作业 → 灭火与投送 / 任务审批 | 一条示例任务的准备、审批/退回、执行与结果流程，跨页面保留 |
| devices / firmware | 设备管理 / 设备维护 / 固件管理 | 台账、详情、视频入口；维护与固件检查为示例 |
| media | 平台管理 → 媒体资料 | 示例资料搜索、预览、关联事件 |
| members | 平台管理 → 成员权限 | 示例成员角色调整；无真实权限校验 |
| layers / flight-area | 平台管理 → 地图与空域 | 展示入口与概览；限制区绘制、图层上传待接原功能 |

## 落地范围

本次只增加 `frontend/prototypes/cockpit` 内的独立原型内容。正式业务页面、后端接口与 Android Agent 未修改。

落地时可按上述入口逐页接回现有功能；航线格式、任务状态、机型能力、审批权限仍以正式系统为准。本版没有覆盖航线高级参数、全部载荷动作、全部空域/图层管理及真实媒体操作，不能据此承诺完整迁移工作量。
