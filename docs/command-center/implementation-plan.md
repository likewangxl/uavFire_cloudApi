## 最新修订：取消重复入口

依据用户实际试用反馈，撤出独立专业作业/旧综合驾驶舱，将两套航线列表合并成一份。审批归灭火任务，处置归火情事件，飞行控制/识别启停归视频窗口。下表和旧阶段记录代表首次实施；最新范围与验证见 consolidation-report.md。

## 关键依赖与实施顺序

1. 共用导航先接两种页面外壳，再替换事件页，避免脱离 Vuex / 地图 / WebSocket 业务上下文。
2. 事件列表、识别历史和处置时间轴独立适配；验证 JSON 与 query 命名差异后修复 workspaceId/limit 序列化。
3. 从浏览器提交审核发现说明留存缺口后，补充 nullable 数据列、事务写入及 DTO。先迁移，再通过后端测试并重新启动。
4. 保留完整规划器，浏览器实际添加航点/选 M300/H20T/保存，再读取正式 API 核对。
5. 视频使用同一正式组件在隔离 API 环境验证窗口行为；真实环境仅验证设备/空流状态，不能虚构在线飞机。
6. 最终使用正式构建冷启动复核，排除开发期热更新导致的旧模块状态。

## 验证反馈引起的具体改动

- 查询参数 camelCase 与全局 snake_case 冲突：为火情列表补充专用 serializer，查询最近200条并明确口径。
- 事件关联后 timeline 不自动更新：同事件轮询后重读详情，仍保持选中事件的请求序号保护。
- 未定位事件显示参考经纬度：新增定位质量判断。
- 复核说明丢失：数据库迁移、事务内 history 字段、审核人和说明显示。
- 未关联处置的已排除事件再次成为候选：复用状态判断过滤。
- 无在线设备无法打开保存对话框：只在打开弹窗阶段允许未选机型，提交校验保留。
- 执行页只显示云端 jobs 导致 M300 航线看起来没有记录：增加航线最近执行与巡检计划两个口径。
- 导航高度、三栏底部溢出、长编号、窄屏按钮及规划工具条：修正尺寸和响应式规则。
- 多源轮询失败反复弹 toast：新页面使用明确错误面板，保持401原有恢复流程。
- 旧测试断言仍要求已移除 KPI 区块、只接受一种过滤语法：核实原组件后修正断言，保留控制面板嵌套与 RC 排除要求。

- 专业驾驶舱旧活跃队列包含已排除事件且未限定工作区：补充当前工作区查询、排除状态过滤及对应回归测试，地图使用相同队列。
- 新增执行页表格亮色冲突：增加局部暗色表头、表格与分页样式。
