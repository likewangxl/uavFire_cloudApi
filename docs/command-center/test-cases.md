## 关键用例的可复现步骤

### EVT-07/08：实际审核与审计

1. 本地 API 正常后运行 `python3 docs/command-center/scripts/api-smoke.py`。脚本创建带 QA-CC 前缀、低置信度、UNLOCATED、DRY_RUN 的独立测试记录；不得替换成现场事件编号。
2. 登录正式页面，按脚本输出的 browserReviewEvent 打开事件。点击人工复核，空说明时“提交复核”应禁用。
3. 选择排除，输入说明并提交。应关闭弹窗、更新已排除状态、减少待复核数、时间轴出现真实审核人和说明。
4. 重新加载页面并 GET 对应 history，说明必须仍存在。脚本还用同一幂等键重复确认另一测试事件，历史中 CONFIRMED 只出现一次。
5. 审核接口失败时状态不得先行变化；此项以业务响应处理单元测试和后端原幂等测试补充，未对真实现场事件故意提交错误状态。

### RT-01：离线保存规划航线

1. 从任务中心打开航线规划，选择监测/航点航线，确定。
2. 在地图点击两个不同点；观察航点数与里程更新。零航点时保存禁用。
3. 点击保存，在弹窗输入 QA-CC 前缀名称，选择 M300、H20T、主云台，保留或调整合法高度/速度。
4. 点击确定，成功后航线库显示草稿、两航点、对应机型；通过 planned-waylines API 读取并核对。
5. 无在线飞机时下发执行继续禁用。不得通过伪造在线状态完成现场飞行验收。

### VID-02/04：隔离窗口与租约

1. 启动 `node frontend/scripts/command-center-fixtures.mjs`（只绑定127.0.0.1:6790）。使用 API/WS 指向6790的独立 Vite端口8081。
2. 以隔离环境的演示登录进入，账户必须显示“隔离测试·无真实设备”；设备名包含“隔离验证”。
3. 打开视频监控，四路应显示“尚无可播放视频流”；不以照片代替直播。
4. 用标题拖动，用缩放柄/方向键修改窗口；平铺、最大化、还原、关闭后检查边界和数量。
5. 申请高清后查询 `/__qa__/leases`，active为1；关闭该窗口后为0。再次申请然后离页，active仍应回到0。
6. 保存布局后刷新，保留打开窗口；全部关闭后的空布局也应保留。此项为布局实现/纯函数覆盖，完整“清空后刷新”浏览器步骤未单独补跑时在报告标注。
7. 此环境不提供媒体传输；解码/真实带宽/飞机上传必须另行实测。

### DATA-01：失败回退

1. 隔离服务 `POST /__qa__/failure {"enabled":true}`。
2. 总览刷新后，各失败数据源应显示错误，统计值为“—”，不能继续显示假在线数。
3. 重复刷新不能积累遮挡操作的同类弹窗；401仍遵循原登录逻辑。
4. 将enabled恢复false后重试，应恢复成功状态。故障注入只针对隔离服务，不停止生产系统。

### VIS：视觉与响应式

1. 使用同一浏览器、同一1440×960视口采集原型与正式火情页，图像均选择可见光。
2. 同时打开两张实际截图，比对三栏比例、顶栏、边距、字体、图片contain、时间轴、状态色和固定操作区。
3. 在1280×900及1792×900复查列宽；在390×844检查全页scrollWidth不大于clientWidth，事件列表横向滚动、详情纵向可达。
4. 对每个P0/P1/P2记录修复前证据、改动、复测截图；未测的设备实流不进入视觉通过结论。
