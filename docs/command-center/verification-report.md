## 复跑方式

1. 保持 MySQL、Redis、MQTT 的本机配置可用，先执行技术方案中的增量迁移。
2. 使用 Java17 执行 `mvn -B -pl uavfire -am package`，再按技术方案启动本地API。不要把普通模块jar误当成已重打包可执行jar。
3. 前端收集 `src/**/*.test.mjs` 运行 `node --test`；使用本机 API/WS 环境变量执行 Vite build，然后preview到8080。
4. 如需再次写入QA数据，运行 `docs/command-center/scripts/api-smoke.py`；每次会生成新的前缀记录，不能把输出ID替换成现场事件ID。
5. 依据测试用例表执行浏览器检查，把新增截图与真实结果补入本报告。设备验收不得用fixture通过代替。
