# 智能集群大载重无人机灭火系统 — 项目介绍

> 版本：2026-06-18
> 用途：面向客户、合作方与评审的平台介绍材料。
> 口径原则：区分「已实装能力」与「演进路线」，不对未落地能力做过度承诺。

---

## 一、平台定位：一个平台，打通"侦察—运载"全链路飞控

**智能集群大载重无人机灭火系统，是一套高度集成的一体化无人机指挥作战平台。它彻底打通了行业无人机（侦察感知）与大载重运载无人机（灭火投送）的飞控与任务链路——客户无需在多套厂商系统、多个操控终端、多个 App 之间反复切换，只需通过单一平台，即可完成从"火情感知"到"精准处置"的全流程作业。**

平台将 **Matrice 4T 行业侦察机** 与 **FlyCart 100 大载重运载机** 纳入同一作战体系，配合 RC Plus 2 前线执行层、RTK 高精度定位与机载载荷，让客户用一个平台就能实现：**异构机队统一管控、行业机与运载机自动飞行与自动任务执行、多机集群协同作业、无人值守自主巡航。**

> 它不是单机巡检工具，而是把"看火的机"和"灭火的机"统一调度的**空地一体化作战平台**。

---

## 二、核心平台能力（重点）

### 能力一｜异构机队统一管控 —— 行业机与运载机"同框纳管"

平台将**侦察型行业无人机（M4T）**与**大载重运载无人机（FC100）**两类异构机型，纳入**同一飞控与任务管理平台**，实现统一接入、统一调度、统一态势呈现。

客户不必为不同机型部署不同系统、培训不同操控终端——**一个平台、一套界面，同时管理"看火的机"和"灭火的机"**。新增机型、新增载荷，平台以统一的任务模型纳管，避免"一机一系统"的烟囱式建设。

### 能力二｜全自主任务链 —— 自动飞行、自动执行任务

平台以**任务编排引擎**驱动无人机完成端到端的**全自主任务链（Autonomous Mission Chain）**：

```
自动起飞 → 航线自主飞行 → 自动执行任务（侦察拍照 / 热成像 / 灭火投放）→ 自动返航降落
```

- **任务下发与机型解耦**：同一套任务编排逻辑，既能驱动行业机执行巡检/复核/侦察，也能驱动运载机执行投送/灭火。
- **作业动作可编排**：航线可逐点配置高度、速度、云台俯仰、拍照、悬停、云台旋转等动作；运载机投放任务支持**到点自动脱钩**。
- **全程闭环反馈**：任务状态、飞行进度、航点动作执行结果实时回传，平台可视、可控、可追溯。

客户只需在平台上**规划任务、一键下发**，无人机即自主执行，无需人工逐步操控飞行。

### 能力三｜集群协同作业 —— 多机编组、侦灭一体

平台面向**多机集群作业**设计，支持多架无人机同时接入、并行管理多路视频流与遥测，形成**"侦察机 + 运载机"协同编组**：

- **侦察机**负责发现火点、确认坐标、回传现场态势；
- **运载机**据此抵达目标区域，携带灭火载荷执行投放；
- 二者在同一平台内协同调度，实现**"侦灭一体"的空地协同闭环**——从"发现火情"到"参与扑救"在一个平台内连续完成。

### 能力四｜无人值守自主巡航 —— 系统值守，异常唤醒

平台支持**无人值守（Unattended）**的周期性巡航监测，把"人盯屏"升级为"系统值守、异常唤醒"：

- **预案航线 + 自动巡航**：无人机按既定航线自动巡查重点林区、景区、输电通道、山地边界等区域；
- **AI 在环（AI-in-the-loop）自动识别**：平台对回传视频流连续进行火焰/烟雾/异常热源识别；
- **异常自动告警留证**：达到风险阈值时，自动生成火情事件、自动保存现场截图、自动分级告警。

值守人员无需全程盯屏，平台在发现异常时主动推送，**大幅降低人工巡护压力，提升大范围、长时段、高风险区域的火情早发现能力**。

### 能力五｜单一平台、统一作战界面（Single Pane of Glass）

指挥驾驶舱将**实时画面、设备状态、火情告警、航线任务、处置进展**集中于统一界面。指挥人员在一个平台内即可完成 **"看态势 → 判火情 → 派任务 → 盯执行 → 做复盘"** 的完整指挥闭环，无需在多个系统间切换，让复杂的底层链路收敛成一套可操作的指挥界面。

## 三、技术支撑（概要）

上述平台能力，由一套自主可控、模块化的技术底座支撑。技术细节从简，关键支撑如下：

| 平台能力 | 关键技术支撑（概括） |
|----------|----------------------|
| 异构机队管控 / 自动飞行 | RC Plus 2 上自研 **MSDK v5 Agent**：遥测上报、直播推流、指令执行、KMZ 航线全链路，摆脱对 Pilot 2 封闭路径的依赖 |
| 任务自动执行 | 后端**航线任务服务** + MSDK v5 航线执行 + 全程状态回传；面状测区自动生成、地形剖面规划 |
| 无人值守识别 | **AI 服务**：可见光（YOLO/启发式）+ 热成像双模态融合识别、风险分级、事件自动回传与截图留证 |
| 火点精确处置 | **射线-DEM 火点定位**：融合 RTK、姿态、云台角、识别框与地形高程，输出带误差半径的真实坐标 |
| 低延时态势汇聚 | **ZLMediaKit 媒体中枢** + RTMP 接入 + WebRTC 低延时播放 |
| 坐标自洽底图 | 地图栈迁移至 **MapLibre + 天地图（WGS84）**，消除第三方加偏地图与无人机坐标系的系统性偏移 |

**技术栈**：Java（Spring Boot，DJI Cloud API 基础）/ Vue 3 + Ant Design Vue / Android DJI MSDK v5（Kotlin）/ Python FastAPI + YOLOv8 + OpenCV / ZLMediaKit / EMQX(MQTT) / MySQL / MinIO / MapLibre + 天地图。

## 五、典型应用场景

1. **林区无人值守巡护**：防火期按预案航线周期性自动巡查，AI 持续识别并自动告警——扩大覆盖、降低人工巡山压力、提早发现火情。
2. **初期火情快速核查**：监控/上报/传感器报警后，一键派机抵近复核，实时回传画面并记录位置、截图与风险等级——减少误报浪费，避免真实火点扩大。
3. **复杂地形火场侦察**：山地、沟谷、林密区域地面视野受限、车辆难抵近，无人机从空中观察火线走势、烟雾扩散与隔离带——提升态势透明度，辅助科学调度。
4. **大载重无人机灭火投放**：侦察机定位火点、确认投放环境，运载机自动抵达执行投放，全程记录航线与处置前后影像——让无人机从"看火"走向"参与灭火"。
5. **夜间与低能见度巡查**：热成像 + 可见光结合，记录热源变化、阴燃热点与疑似火点——补足夜间人工巡查与普通监控的短板。
6. **多机集群协同作业**：多架侦察机分区巡查、运载机随队待命，统一平台调度编组——应对大范围、多火点的复杂火场。
7. **灾后评估与复盘**：保留事件、截图、轨迹、进度与状态，复盘响应时间、任务调度与作业效果——支撑战术优化、责任追溯与装备评估。

## 六、为客户解决的核心问题

森林消防的传统痛点：**发现晚、判断难、响应慢、作业险、调度散、复盘缺**。本平台逐一对应：

| 客户痛点 | 平台如何解决 |
|----------|--------------|
| **机型多、系统散**：不同机型各用各的系统与终端，难以统一指挥 | 一个平台纳管行业机与运载机，统一接入、统一调度、统一界面 |
| **操控重、门槛高**：依赖人工逐步操控飞行，作业效率低 | 任务化作业，规划即下发，无人机全自主飞行与执行 |
| **发现晚**：人工巡查覆盖有限、初期火点发现滞后 | 无人值守自主巡航 + AI 在环识别，系统替人盯屏、主动告警 |
| **响应慢**：地面人车进入困难，错过早扑窗口 | 侦灭一体：侦察机定位、运载机据坐标自动抵达处置，缩短决策到行动链路 |
| **作业险**：人员暴露在高温、浓烟、复杂地形 | 无人机进入人员不宜抵达区域执行侦察与投放，减少一线涉险 |
| **难追踪**：多机多任务缺乏统一调度与过程记录 | 全程遥测/事件/轨迹留痕，每架机、每个任务均可调度可追溯 |
| **缺复盘**：灭火、巡检、复盘数据链路割裂 | 火情事件、截图、航线、遥测全量沉淀，形成可回放、可分析的数据底座 |

**一句话价值**：**一个平台，统管侦察与运载机队；自动飞行、自主巡航、集群协同——让森林消防发现更早、响应更快、作业更安全、指挥更直观。**

## 七、能力边界与演进路线（如实说明）

为建立长期信任，明确区分当前能力与演进方向：

**已实装、可演示**
- 行业机与运载机统一接入与任务下发，全自主航线飞行与任务执行（含运载机投放到点自动脱钩）
- 自研 MSDK Agent：遥测、推流、指令执行、航线全链路、飞控、热成像帧探针
- AI 实时识别：可见光 + 热成像融合、风险分级、事件自动回传与截图留证
- 单帧射线-DEM 火点定位（带误差半径）
- 航线规划全套（面状测区/地形剖面/航点动作/测距）
- 指挥驾驶舱统一态势 + WebRTC 直播 + 火情事件工作流
- MapLibre + 天地图 WGS84 自洽底图

**演进路线（设计完成 / 持续工程化）**
- **多机自主集群协同调度**：平台已支持多机同时接入与并行管理，全自主集群编队/任务自动分配持续工程化
- **多视角亚米级火点定位**：交会解算与自动补观测已完成设计，待实现与实飞标定（当前为单帧定位，米级精度）
- **双模态独立实时流**：受机载硬件单流限制，当前为可见光推流 + 热成像帧旁路；双模态能力持续演进
- **AI 模型效果**：可接入并基于现场数据持续训练调参，不承诺生产级准确率
- **无人值守自动化**：预案巡航 + AI 自动告警已实装；定时调度、机库/自动续航等全无人值守能力持续完善
