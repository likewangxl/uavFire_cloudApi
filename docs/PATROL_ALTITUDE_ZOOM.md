# 航线巡航按高度变焦

标定基准为 30 米、2 倍，巡航云台俯仰为 -45°。连续变焦镜头的请求倍率为
`round((heightM / 30 * 2) * 10) / 10`：35 米为 2.3 倍，40 米为 2.7 倍。

## 高度与画质条件

当前高度取自 DJI `KeyAircraftLocation3D.altitude`，沿用 Agent 的相对起飞点高度口径。
它不是实时离地高度：这一版适用于巡查地面与起飞点基本同高的情况，没有实现地形补偿。
30 米、2 倍的有效性需要在 -45°、相同镜头及相同识别视频分辨率下复测。
倍率缩放只维持近似目标成像大小，不保证数字放大后的细节或识别率。

## 执行行为

- AppServices 为 WaypointMissionExecutor 注入自动变焦控制器。
- 只有本 Agent 启动的任务收到 DJI `EXECUTING` 状态后才开始循环；每轮结束后间隔 1 秒。
- 云台实际俯仰偏离 -45°超过 5°、高度无效或镜头能力未知时，不下发倍率。
- 在可见光源下选择变焦镜头；热成像及其他不支持的视频源不被强制切换。
- 读取当前镜头的倍率范围：连续范围按 0.1 倍计算并限制上下限；固定档位取最近支持档位。
- 小于 0.2 倍的目标变化使用防抖；当前倍率被其他流程重置时重新纠正。
- 使用变焦镜头索引设置倍率，读取实际倍率确认。回读误差小于 0.05 倍才记为成功。
- 接口失败或回读不符，记录日志并等待 5 秒重试；不会因此重启或中断航线。
- 暂停、停止、中断、结束或卸载监听器时取消循环。火情确认先等待已发出的自动相机操作结束，再执行暂停及自己的相机控制。
- 恢复任务后重新设定 -45°，等待 EXECUTING 状态及实际俯仰就绪后恢复变焦。

可通过 Android 日志 `WaypointMissionExecutor` 下的 `patrol zoom` 查看等待原因、相对高度、目标倍率和回读倍率。
航线执行期间手动改倍率可能被自动策略纠正；显式改变云台角度到允许范围之外或切换热成像时自动倍率暂停。

## 验证

`PatrolZoomControllerTest` 覆盖非整十米高度、镜头上下限、离散档位、防抖、无效高度、
不符的云台角度、热成像占用、外部倍率复位及回读失败重试。

真机验收应对照 30/35/40/60 米的高度、云台实际 -45°和实际倍率，同时检查识别输入画面；
测试暂停/恢复、火情确认和视频源切换。单元测试不能代替真机验证。
