# 白色主题与移动端交互检查

日期：2026-09-15。

本轮按用户手机截图修改原生 `miniprogram/` 工程，使用白色背景、黑灰文字、浅灰分区与明确按钮边界。任务、火情、报告筛选统一为原生 picker；列表长名称自动换行，长事件编号在详情完整展示并可复制。

## 使用浏览器检查

在 `miniprogram/` 执行 `npm run preview`，程序会自行启动仅监听本机的检查服务并打印地址；默认端口被占用时自动选择空闲端口。默认使用本机已安装的微信 WXML 编译器，其他安装路径可通过 `WECHAT_WCC` 指定。

检查页支持切换页面、屏幕宽度与数据状态。`preview/`、`tests/`、`scripts/` 已加入微信打包忽略列表。该环境只使用标注的测试数据，不发送真实微信登录或业务写入请求。
