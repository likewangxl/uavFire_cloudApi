# 火情事件最新状态与历史记录设计

## 目标

火情事件列表展示每个聚合事件的最新识别状态；用户点击事件后可以查看该事件从创建到每次合并命中的历史快照。

## 设计

- `fire_event` 继续作为事件主表，语义调整为“当前最新状态”。合并命中时更新 `confidence`、`fire_level`、温度、图片、最近命中时间和计数。
- 新增 `fire_event_history` 表，记录每次创建或合并时的快照，包括父事件 ID、源事件 ID、置信度、等级、温度、图片、时间戳和合并动作。
- 通知仍只在等级升级时递增 `notification_version`，避免列表降级导致重复通知。
- 前端列表增加“查看历史”操作，打开抽屉显示该事件历史命中记录。

## 验收

- 新合并的 LOW 可以把列表中的 HIGH 降为 LOW。
- 历史接口能返回创建和合并快照。
- 前端能从列表查看历史记录。
