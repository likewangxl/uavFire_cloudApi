# RC Plus Agent Android 启动图标设计

## 目标

为 `rcplus-msdk-agent` 制作并接入一套新的 Android 启动图标。图标必须同时传达无人机、主动监测和消防火情三个信息，其中无人机监测是第一视觉层级，消防火情是被监测目标。

## 视觉方向

采用“空中热源锁定”方案，整体为立体科技风：

- 深色四旋翼无人机占据画面中心和主要面积，使用略俯视的三分之四视角。
- 无人机机腹搭载清晰可见的热成像或光电监测云台。
- 云台向下发出红橙色锥形扫描光束，锁定一个简化的小型火点。
- 火点周围使用同心热成像圆环和准星，强化监测、识别和定位语义。
- 背景使用炭黑到深红渐变，并以少量冷蓝边缘光表现科技装备质感。
- 画面不使用文字、消防斧、盾牌或复杂场景，避免弱化无人机监测主体。

## 构图与小尺寸表现

- 无人机主体位于自适应图标安全区域内，不让旋翼或机臂依赖画布边缘。
- 火点和扫描图形保持简洁，不出现真实烟雾、树林、建筑或人物。
- 强调大轮廓、明暗对比和有限色彩，确保图标缩小至启动器常见尺寸后仍可识别。
- 不使用细小文字、细线网格、水印、品牌商标或摄影式背景。

## Android 资源设计

图标采用 Android Adaptive Icon 结构：

- 前景层：无人机、云台、扫描光束、热成像圆环和火点。
- 背景层：炭黑到深红的科技感底色。
- 自适应图标 XML：供支持 Adaptive Icon 的 Android 版本使用。
- 兼容位图：为旧版本 Android 和不支持自适应图标的启动器提供各密度资源。
- 圆形图标入口与普通图标入口使用同一套视觉资产。

`AndroidManifest.xml` 将显式设置 `android:icon` 和 `android:roundIcon`，替换当前未声明图标时使用的默认占位图标。

## 验收标准

- 第一眼能够识别为无人机监测类应用。
- 第二视觉信息能够识别出被锁定的消防火情。
- 图标具有立体科技感，且不是传统消防徽章风格。
- 在圆形、圆角方形和方形遮罩下，核心主体均不被裁切。
- Android 资源编译通过，Manifest 正确引用新图标。
- 生成资产中不包含文字、水印、第三方商标或 DJI 品牌元素。

## 验证

- 检查生成图像的主体、构图、颜色和禁用元素。
- 预览前景在常见 Adaptive Icon 遮罩下的安全区域。
- 运行 Android 资源处理或项目构建任务，确认资源命名与 Manifest 引用有效。
- 检查 Git 变更，确保只包含设计说明、图标资源和必要的 Manifest 配置。
