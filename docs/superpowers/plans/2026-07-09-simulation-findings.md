# 对抗性模拟测试发现（2026-07-09，Round 1–3 新功能）

**方法**：在 uavfire-verify 副本对真实代码注入恶劣物理场景（fake 硬件），5 个探针测试全部实跑证实；另有代码走查发现。探针为一次性实验，未入库（副本下次 robocopy 会清除）。

## 探针证实的缺陷（按严重度）

### F1 🔴 抵近作业上报被后端热图门整个丢弃——激光坐标从未真正落库

- **证据**：`FireConfirmationProcessor` 上报永远 `thermalImageUrl=null`（近测快照路径 `thermalSnapshotPath` 被忽略，从不上传）；后端 `DualStreamServiceImpl:798`——热确认事件无热图 → 置 `THERMAL_IMAGE_MISSING` 直接 return，**不进 `createConfirmedFireEvent`**。
- **后果**：生产环境中抵近作业的全部产出（近测温度、激光米级坐标、PRECISE 质量）在后端被静默丢弃；TC1-B 后端测试直接构造了带图参数所以全绿——端到端断链单测测不出。此前"激光坐标落库链路闭环"的结论**不成立**。
- **修复**：agent 侧 processor 复用 `ThermalSnapshotUploader` 上传近测快照并携带 URL（与 Monitor 同约定）；上传失败时降级路径可考虑后端"合并进已有带图事件时放行 geo 字段"（合并不新建，证据契约不破坏）。

### F2 🔴 激光背景命中无位移校验：222m 偏移坐标以"误差 5m"入库

- **证据**：探针 `probe_background_hit_accepted...`——激光越过火点打中后方山坡（260m，在 3×预期斜距门限内、散布≈0）→ fix 被采信；偏离疑似点 222m 的坐标以 geoErrorRadiusM=5 + PRECISE 上报；第二段照山坡飞；**飞行高度直接采用激光返回海拔 300m**。
- **后果**：自动航点门禁会放行这个错误坐标 → 灭火弹投到空山坡。
- **修复**：①fix 与疑似坐标位移 > 门限（建议 80m，可配）→ 降级不采信（记 LOW）；②飞行高度不得采用激光/事件海拔，保持机体当前高度（与实机验证 F1 高度基准问题同源）。

### F3 🟠 散布检查"全弃制"：2 个烟回波连坐 3 个完美样本

- **证据**：`probe_smoke_echo_mix...`——5 样本中 2 个烟柱假回波（坐标偏 39m）+3 个真实 → 任意两点超 15m 即全弃 → laserFix=null。烟雾恰是森林火场常态，这会让激光在最需要时失效。
- **修复**：中位数修剪——按分量中位数剔除偏离 > 门限的离群样本，剩余 ≥3 个则采信。

### F4 🟠 dwell 链路抖动消耗采样预算：全部有效读数超阈值仍被拒

- **证据**：`probe_alternating_failures...`——4 样本预算中交替失败（不连续、不触发 fail-open）占掉 2 个,有效读数 46/48°C 全超阈值,命中 2<3 → 拒绝上报。
- **修复**：失败不计入采样预算（顺延补测,设总尝试上限）,或命中判定改按"有效样本命中比例"。

### F5 🟠 末段测温失败丢弃已到手的激光 fix

- **证据**：`probe_final_leg_measure_failure...`——第一段已获合格测温+HIGH 激光 fix,第二段测温故障 → 整体 abort,零上报。
- **修复**：保留最近一次合格测量与 fix 做兜底上报（降级标记）。

### F6 🟡 可见光确认在环绕最后点（下风侧）拍摄

- **证据**：`probe_visible_confirm_shot_from_downwind...`——北风时环绕 0°→120°→240°,可见光在 240°（下风象限）隔烟拍摄。
- **修复**：环绕结束回上风点再拍,或把可见光拍摄挪到上风首点。

## 代码走查发现（无法探针）

- **F7 🟠 无电量/RTH/接管守卫**：作业最坏 ~7.5min（两段×90s + 三点×90s + 采样),期间无电量门槛、无总时长上限、无"位置持续背离目标=被接管"检测;低电 RTH 触发后作业与 RTH 竞争,靠层层超时自然退出,RESET 在 RTH 中恢复航线可能失败（已容忍但混乱）。建议:起始电量门槛 + 作业总时长上限 + 背离即中止。
- **F8 🟢 环绕首点与末段悬停点重合**,浪费一次 flyTo(无害,可跳过)。
- **F9 🟢 火线蔓延语义**：火头移动 >40m 会产生新事件而非更新旧事件(去重按事件坐标,坐标只被更优 geo 覆盖)——多事件表现是否符合产品预期待定,记录备忘。
